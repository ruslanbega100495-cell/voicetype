FAQ

Questions answered


Do I need a Groq account?
+

Yes — Groq provides the AI transcription engine. Sign up free at console.groq.com and create an API key in seconds. Their free tier is very generous — easily covers hundreds of dictations per day.

Will it work without internet?
+

VoiceType can fall back to local Whisper (offline mode) if no Groq key is set. Offline mode works 100% without internet but requires more RAM and is slower. For best results, use Groq.

Which Windows versions are supported?
+

Windows 10 and Windows 11 (64-bit). No installation needed — just run VoiceType.exe directly. No admin rights required.

How do I get my PRO license key after purchase?
+

Gumroad sends your license key by email immediately after payment. Open VoiceType → Settings → License key, paste it in, and the status turns green instantly. No internet check needed — validation is offline.

Can I use it in Russian or Ukrainian?
+

Absolutely. Set language to "auto" — VoiceType detects automatically — or pin a specific language in Settings. Russian, Ukrainian, German, French, Spanish, Chinese and 40+ more are supported natively by Whisper.
