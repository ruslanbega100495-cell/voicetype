FAQ

Do I need a Groq account?

Yes — Groq provides the AI transcription. Sign up free at console.groq.com and create an API key. Groq's free tier is generous and more than enough for daily use.

Will it work without internet?

VoiceType falls back to local Whisper (offline mode) if no Groq key is set. Local mode requires more RAM and is slower, but works 100% offline.

Which Windows versions are supported?

Windows 10 and Windows 11 (64-bit). No installation needed — just run the .exe.

How do I get my PRO license key after purchase?

Gumroad sends your license key by email immediately after payment. Paste it into VoiceType → Settings → License key. That's it.

Can I use VoiceType in Russian / Ukrainian / other languages?

Yes. Set language to "auto" and VoiceType detects it automatically, or pin a specific language in Settings.
